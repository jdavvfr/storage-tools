# RAID Calculator

Free online RAID calculator.

Supported RAID levels:

- RAID 0
- RAID 1
- RAID 5
- RAID 6
- RAID 10
- RAID 50
- RAID 60

Features:

- Capacity calculation
- Hot spare sizing
- Rebuild estimation
- Storage efficiency
- TiB / PiB conversion
